O que é argumentação lógica?Fundamento essencial

Um argumento lógico é um conjunto de premissas (afirmações iniciais) que sustentam uma conclusão (afirmação final). A ideia é usar a razão para justificar uma posição.

Exemplo clássico
Premissa 1: Todos os homens são mortais.
Premissa 2: Sócrates é homem.
Conclusão: Sócrates é mortal.
💡 Analogia: Argumento é como uma receita. As premissas são os ingredientes, a conclusão é o prato final. Se os ingredientes são bons e a receita é seguida, o prato fica bom.
⚠️ Não é argumento: "Feche a porta!" (ordem), "Que dia lindo!" (exclamação). Argumentos exigem justificação.
📌

Premissas e ConclusãoA estrutura básica

Premissa = afirmação apresentada como evidência. Conclusão = afirmação apoiada pelas premissas.

P1: Se chove, a rua fica molhada.
P2: Está chovendo.
Conclusão: A rua está molhada.
Válido
P1: Todos os gatos são mamíferos.
P2: Bola é um gato.
Conclusão: Bola é mamífero.
Válido
🔎 Dica: Identifique as premissas procurando por palavras como "porque", "já que", "dado que". A conclusão geralmente vem após "logo", "portanto", "assim".
🔄

Tipos de raciocínioDedutivo vs. Indutivo

Raciocínio Dedutivo

Parte de premissas gerais para uma conclusão específica. Se as premissas são verdadeiras, a conclusão necessariamente é verdadeira.

Exemplo
"Todo ser humano respira. João é humano. Logo, João respira."

Raciocínio Indutivo

Parte de casos específicos para uma conclusão geral. A conclusão é provável, mas não garantida.

Exemplo
"Observei 100 cisnes brancos. Logo, todos os cisnes são brancos." (conclusão provável, mas pode haver cisne preto)
⚖️ Comparação: Dedutivo = certeza (se premissas verdadeiras). Indutivo = probabilidade (baseado em evidências).
✅

Validade e SolidezForma versus conteúdo

Argumento válido = a conclusão segue obrigatoriamente das premissas (coerência lógica). Argumento sólido = válido + premissas verdadeiras no mundo real.

P1: Todos os mamíferos voam.
P2: Homens são mamíferos.
Conclusão: Homens voam.
Válido (mas falso)
P1: Todos os mamíferos respiram.
P2: Homens são mamíferos.
Conclusão: Homens respiram.
Sólido (válido + verdadeiro)
🧠 Macete: Validade = estrutura. Solidez = estrutura + verdade. Uma frase pode ser válida, mas absurda se as premissas forem falsas.
🚨 Pegadinha: "Se estudo, passo. Passei, logo estudei." — INVÁLIDO (falácia da afirmação do consequente).
⚠️

Falácias comunsErros que enfraquecem um argumento

Ad Hominem
Atacar a pessoa em vez do argumento.
Ex: "Você não pode defender a reciclagem porque você não é ecologista."
Apelo à Emoção
Usar emoção (medo, piedade) no lugar de prova lógica.
Ex: "Doe para esta causa, senão essas crianças vão sofrer."
Falsa Dicotomia
Apresentar apenas duas opções, ignorando alternativas.
Ex: "Ou você está comigo, ou contra mim."
Afirmação do Consequente
Concluir a causa a partir do efeito.
Ex: "Se estudo, passo. Passei, logo estudei."
🔍 Dica: Sempre questione: "A conclusão realmente decorre das premissas? Há alguma suposição escondida?"
🏗️

Estrutura de argumentosComo organizar

Um argumento bem estruturado segue um formato claro:

Premissa 1 → Premissa 2 → ... → Conclusão

Exemplo completo
P1: Se chove, então a rua fica molhada.
P2: Está chovendo.
Conclusão: A rua está molhada.
🧠 Macete: Use conectivos lógicos para testar a validade: Se P então Q; P; logo Q (Modus Ponens).

Diagramas LógicosVisualize com círculos

O que são diagramas lógicos?

Imagine que você tem caixas (ou círculos) para guardar coisas. Cada caixa representa um grupo: a caixa dos cachorros, a caixa dos animais, a caixa dos gatos. Os diagramas lógicos são desenhos que mostram como essas caixas se relacionam: uma dentro da outra, separadas, ou se sobrepondo.

Eles servem para resolver questões de concurso que falam de "Todo", "Nenhum", "Algum". Em vez de ficar imaginando, você desenha e vê a resposta.

💡 Dica: Os círculos representam conjuntos. A posição deles mostra a relação entre os grupos. Depois de desenhar, fica muito mais fácil saber o que é verdade ou mentira.

Os 3 desenhos que você precisa saber

Existem três frases básicas que caem em prova. Veja como desenhar cada uma:

Todo A é B
O círculo A está inteiramente dentro do círculo B.
Exemplo
"Todo cachorro é animal." (cachorro dentro de animal)
⚠️ Cuidado: Não vale ao contrário! "Todo A é B" não significa que "Todo B é A". Nem todo animal é cachorro.
Nenhum A é B
Os círculos estão separados, sem interseção.
Exemplo
"Nenhum peixe é mamífero." (peixes e mamíferos não se misturam)
Algum A é B
Existe uma interseção entre os círculos (pelo menos um elemento em comum).
Exemplo
"Algum médico é professor." (existe pelo menos uma pessoa que é as duas coisas)
📌 Nota: "Algum" significa "pelo menos um". Pode ser que todos sejam, mas o mínimo é a interseção.

Como resolver questões com diagramas (passo a passo)

1

Ignore o mundo real

Na lógica de concursos, só vale o que a questão diz. Se ela afirmar "Todo gato voa", aceite e desenhe isso, mesmo que na vida real não seja verdade.

2

Desenhe primeiro as certezas

Comece pelos "Todos" e "Nenhuns", pois eles fixam a posição dos círculos de forma definitiva.

3

Depois encaixe os "Alguns"

Os "Alguns" são mais flexíveis. Desenhe a interseção de forma que fique de acordo com as outras informações. Se houver mais de uma possibilidade, considere todas.

4

Analise as alternativas

Elimine as opções que são falsas em pelo menos um dos desenhos possíveis. A resposta correta é aquela que é sempre verdadeira, em qualquer configuração.

Exemplo prático de concurso

Enunciado:

"Sabendo que todo gato é felino e que algum felino é preto, é correto afirmar que..."

Gato dentro de Felino, e Felino intersecta Preto (pode haver gato preto ou não).

Alternativas falsas (pegadinhas):

  • ❌ "Todo gato é preto" — o círculo do gato pode não tocar o preto.
  • ❌ "Nenhum gato é preto" — pode haver gato na interseção felino-preto.
  • ❌ "Todo felino é preto" — o círculo do felino é maior que o preto, nem tudo é preto.

Alternativa correta: aquela que é garantida, como "Existe felino que é gato" ou "Algum felino é gato".

🎯 Macete: Em questões com "Todo", "Nenhum" e "Algum", a conclusão correta é aquela que não pode ser falsa em nenhum desenho possível.

Resumo dos 3 desenhos

FraseDesenhoSignificado
Todo A é B A dentro de B Todo elemento de A também está em B. Não vale o contrário.
Nenhum A é B Círculos separados Não há elemento em comum entre A e B.
Algum A é B Círculos com interseção Existe pelo menos um elemento que pertence aos dois grupos.

Exercícios com gabaritoPratique agora

1. Classifique como válido ou inválido:

"Todos os pássaros têm asas. João é pássaro. Portanto, João tem asas."

Ver resposta

Válido — a conclusão segue das premissas.

2. Qual a falácia?

"Você não pode confiar no estudo sobre reciclagem porque quem defende reciclagem só quer parecer ecológico."

Ver resposta

Ad Hominem — ataca a pessoa em vez do argumento.

3. Complete o argumento:

Premissa 1: "Se como muito, então ___."

Premissa 2: "___."

Conclusão: "Logo, estou satisfeito."

Ver resposta

P1: "Se como muito, então fico satisfeito." P2: "Comi muito."

4. Identifique o erro:

"Ou você é a favor da pena de morte, ou é contra a justiça."

Ver resposta

Falsa Dicotomia — apresenta apenas duas opções, ignorando outras possibilidades.
