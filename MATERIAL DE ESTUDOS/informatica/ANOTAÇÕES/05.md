# Programa de Navegação
---

## O que é um Navegador (Browser)?

**Objetivo:** exibir sítios web (páginas da internet) e permitir a interação do usuário com o conteúdo.  
**Linguagens interpretadas:** HTML, CSS, JavaScript (e outras tecnologias como WebAssembly).  
O navegador renderiza o código HTML/CSS e executa scripts JS para criar páginas dinâmicas.

---

## Conceitos Fundamentais

- **WWW (World Wide Web)** — sistema de páginas e documentos interligados acessados pela internet.  
- **URL (Uniform Resource Locator)** — endereço completo de um recurso na internet. Ex: `https://google.com.br`  
- **HTML (HyperText Markup Language)** — linguagem de marcação de HyperTexto usada para criar e estruturar páginas web.  
- **Porta padrão HTTP = 80** | **Porta padrão HTTPS = 443**

---

### 🔴 1. URL — aprofundar (decomposição)

Uma URL pode ser decomposta em partes:

`https://www.exemplo.com.br:443/pasta/pagina?nome=joao#secao`

- `https` → protocolo  
- `www` → subdomínio  
- `exemplo` → domínio  
- `.com` → domínio de nível (gTLD)  
- `.br` → código do país (ccTLD)  
- `:443` → porta  
- `/pasta/pagina` → caminho  
- `?nome=joao` → parâmetros/query string  
- `#secao` → fragmento  

**Diferenciação importante:**  
**URL** (Localizador Uniforme de Recursos) → endereço completo.  
**URI** (Identificador Uniforme de Recursos) → conceito mais amplo que inclui URL e URN.  
**URN** (Nome Uniforme de Recursos) → identifica um recurso por nome, sem localização.

### 🔴 2. HTTP — aprofundar

Além da diferença entre HTTP e HTTPS, estude os **métodos HTTP**:

- **GET** – obter um recurso  
- **POST** – enviar dados para criar um recurso  
- **PUT** – atualizar um recurso por completo  
- **PATCH** – atualizar parcialmente um recurso  
- **DELETE** – remover um recurso  
- **HEAD** – obter apenas os cabeçalhos (sem corpo)  
- **OPTIONS** – consultar métodos suportados  

**Códigos de status HTTP** (muito cobrados em prova):

| Código | Significado |
|--------|-------------|
| 200 | OK – requisição bem‑sucedida |
| 201 | Created – recurso criado |
| 301 | Redirecionamento permanente |
| 302 | Redirecionamento temporário |
| 400 | Requisição inválida (Bad Request) |
| 401 | Não autenticado |
| 403 | Acesso proibido (Forbidden) |
| 404 | Recurso não encontrado |
| 500 | Erro interno do servidor |
| 502 | Bad Gateway |
| 503 | Serviço indisponível |

**Requisição × Resposta:**  
- **Request** – mensagem enviada pelo cliente (contém método, cabeçalhos, corpo)  
- **Response** – mensagem retornada pelo servidor (contém status code, cabeçalhos, corpo)

### 🔴 3. HTTPS e TLS

Sua anotação já menciona SSL/TLS, mas aprofunde:

- **SSL** (Secure Sockets Layer) – protocolo antigo, obsoleto e inseguro.  
- **TLS** (Transport Layer Security) – sucessor do SSL, atualmente utilizado.  
- **Certificado digital** – associa uma chave pública a uma entidade (emitido por uma Autoridade Certificadora – CA).  
- **Chave pública** – usada para cifrar dados; pode ser compartilhada.  
- **Chave privada** – usada para decifrar; secreta.  
- **Criptografia** – garante confidencialidade.  
- **Autenticação do servidor** – prova que o servidor é quem diz ser.  
- **Integridade** – os dados não são alterados durante a transmissão.

⚠️ **Pegadinha:** HTTPS utiliza **TLS**, não SSL (embora muitas vezes se fale “SSL/TLS”).

### 🔴 4. DNS (Domain Name System)

O DNS converte nomes de domínio em endereços IP.

- **DNS recursivo** – consulta em nome do cliente e retorna a resposta final.  
- **DNS autoritativo** – detém os registros oficiais de um domínio.  
- **Servidores raiz (Root servers)** – apontam para os servidores TLD.  
- **TLD** (Top‑Level Domain) – `.com`, `.org`, `.br`, etc.  
- **Cache DNS** – armazena respostas temporariamente para acelerar consultas.  
- **Registros DNS:**  
  - **A** – mapeia nome → IPv4  
  - **AAAA** – mapeia nome → IPv6  
  - **CNAME** – alias (apelido)  
  - **MX** – servidor de e‑mail  
  - **NS** – servidores de nomes autoritativos  
  - **TXT** – texto arbitrário (verificações)

Exemplo: `google.com` → resolve para um endereço IP (ex: 142.250.190.46).

### 🔴 5. Domínios

- **Domínio** – nome único que identifica um site (ex: `exemplo`).  
- **Subdomínio** – parte adicional à esquerda do domínio (ex: `www`).  
- **TLD** – extensão do domínio (`.com`, `.org`, `.net`).  
  - **gTLD** (genérico) – `.com`, `.org`, `.net`.  
  - **ccTLD** (código de país) – `.br`, `.us`, `.uk`.  

Exemplo: `www.exemplo.com.br`  
- `.br` → ccTLD (Brasil)  
- `.com` → gTLD (comercial)  
- `exemplo` → domínio  
- `www` → subdomínio

## HTTP × HTTPS

- **HTTP** — sem criptografia. Dados trafegam em texto aberto. Inseguro.  
- **HTTPS** — com criptografia (HTTP over TLS). Dados protegidos. Seguro.  
O “S” do HTTPS significa **Secure** (seguro).  
Prova ama cobrar isso — saiba distinguir!

## Navegadores (Browsers)

Programas usados para acessar e exibir páginas web.

- **Chrome** e **Edge** — ambos baseados no projeto de código aberto **Chromium**.  
- **Firefox** — código aberto; possui recurso nativo de Pocket (lista de leitura).  
- **Tor** — rede/sistema de comunicação voltado à privacidade e ao anonimato; sites `.onion` são acessíveis por meio da rede Tor.  
- **Safari** — navegador da Apple, baseado no WebKit.  
- **Opera** — navegador com recursos integrados (VPN, bloqueador de anúncios).  
- **Brave** — foco em privacidade, bloqueia anúncios e rastreadores por padrão.  

⚠️ **Importante:** Chromium ≠ Google Chrome. O Chrome é baseado no Chromium, mas contém componentes proprietários (como suporte a DRM, integração com Google).

## HTML × CSS × JavaScript

- **HTML** – estrutura da página (títulos, parágrafos, tabelas). Não é linguagem de programação; é de marcação.  
- **CSS** – estilo/apresentação (cores, fontes, layout). É uma linguagem de estilo.  
- **JavaScript** – comportamento/interatividade (cliques, animações, requisições). É uma linguagem de programação.

## Complementos (Addons)

- **Plugin:** módulo que estende a funcionalidade do navegador para fazer o site funcionar (ex: Java, Flash – obsoleto, leitores de PDF). Normalmente são instalados à parte e atuam em nível de sistema.  
- **Extensão:** pequeno programa que o usuário instala para personalizar a experiência (ex: AdBlock, temas, gerenciadores de senha). São desenvolvidas com HTML, CSS e JS e integram-se à interface do navegador.

Ambos são chamados de **addons**, mas têm propósitos distintos: plugin habilita conteúdo, extensão adiciona recursos.

## Tipos de Web

- **Surface Web** — sites indexados por mecanismos de busca (Google, Bing). A parte “visível” da internet.  
- **Deep Web** — conteúdo não indexado (e‑mail, banco online, sistemas corporativos, portais privados). A maioria da internet está aqui.  
- **Dark Web** — parte da Deep Web acessada com o navegador Tor; oferece anonimato e pode hospedar conteúdos ilegais.  

⚠️ **Deep Web ≠ conteúdo ilegal.** A Dark Web é uma subparte da Deep Web; a própria Dark Web não é crime, mas pode conter atividades ilegais.

## Navegação Anônima (Privada / InPrivate)

Ao ativar o modo anônimo, o navegador **não salva** localmente:  
- Histórico de navegação  
- Cookies e dados de sites  
- Cache  
- Dados de formulários e senhas  

**NÃO torna o usuário anônimo na internet** — o provedor de internet (ISP), a rede da empresa/escola, os sites visitados e qualquer malware instalado no computador ainda podem rastrear a atividade.  

O modo anônimo **protege apenas os dados salvos localmente** durante a sessão; ao fechar a janela, esses dados são descartados.

⚠️ **Nuance:** O modo anônimo não salva senhas, mas se você estiver logado em um site (ex: Gmail), sua sessão continua ativa enquanto a janela estiver aberta; além disso, o site pode registrar sua visita.

## Dados de Navegação e Cookies

### Cache
Armazena cópias locais de arquivos de sites (imagens, scripts, CSS).  
**Objetivo:** acelerar o carregamento em visitas futuras ao mesmo site.  
São arquivos temporários que podem ser apagados a qualquer momento.

### Cookies
Pequenos arquivos de texto salvos no computador pelo site.  
Armazenam: preferências do usuário, login, carrinho de compras, sessão ativa.  
São considerados dados sensíveis / pessoais (privacidade).  
Podem ser usados para rastrear o comportamento de navegação.

**Aprofundamento:**  
- **Cookie de sessão** – expira ao fechar o navegador.  
- **Cookie persistente** – possui data de validade, permanece após fechar o navegador.  
- **Cookie primário (first‑party)** – criado pelo site que o usuário visita.  
- **Cookie de terceiros (third‑party)** – criado por domínio diferente, usado para rastreamento entre sites (ex: anúncios).  
- **Cookie seguro (`Secure`)** – só enviado via HTTPS.  
- **`HttpOnly`** – impede acesso via JavaScript (protege contra XSS).  
- **`SameSite`** – controla envio do cookie em requisições entre sites (ajuda contra CSRF).  
- **Consentimento de cookies** – exigido pela LGPD/GDPR para cookies de rastreamento.

⚠️ **Pegadinha:** cookie **não é vírus**, não é um programa executável; é um arquivo de texto.

### Histórico
Lista de todos os sites acessados com data e hora.  
Permite retornar a páginas visitadas anteriormente.

### Favoritos / Marcadores
Salva atalhos para sites que o usuário deseja acessar facilmente depois.  
Atalho para adicionar favorito: `Ctrl + D`.

### Itens Salvos – Não são apagados automaticamente
- **Favoritos / Marcadores** – permanecem até o usuário removê‑los.  
- **Lista de Leitura / Coleção** – páginas salvas para ler depois (ex: Pocket, lista nativa do Firefox/Edge).  
- **Downloads** – arquivos baixados ficam na pasta de downloads. O navegador mantém um histórico de downloads, mas os arquivos físicos não são apagados automaticamente.

**Tabela comparativa (muito cobrada):**

| Recurso      | Finalidade                                           |
| ------------ | ----------------------------------------------------- |
| Cache        | Acelerar carregamento de páginas                      |
| Cookie       | Armazenar informações da sessão/preferências          |
| Histórico    | Registrar páginas visitadas                           |
| Favoritos    | Guardar links escolhidos pelo usuário                 |
| Download     | Guardar arquivos baixados                             |

## 🔴 14. Downloads e Uploads

- **Download:** transferência de dados **do servidor para o dispositivo** (ex: baixar um arquivo).  
- **Upload:** transferência de dados **do dispositivo para o servidor** (ex: enviar uma foto).  

⚠️ **Pegadinha clássica:** não confundir os sentidos!

## 🔴 15. Streaming

- **Streaming:** exibição de conteúdo (áudio, vídeo) em tempo real, sem necessidade de baixar o arquivo completo antes.  
- **Buffer:** armazenamento temporário de dados para compensar variações de rede.  
- **Streaming ao vivo** (live) – transmissão em tempo real (ex: eventos).  
- **Streaming sob demanda** – conteúdo disponível para assistir a qualquer momento (ex: Netflix, YouTube).

## 🔴 17. Armazenamento local do navegador

Além dos cookies, o navegador oferece outras formas de armazenamento:

- **Local Storage** – dados persistentes, sem expiração, até 5‑10 MB.  
- **Session Storage** – dados temporários, expiram ao fechar a aba.  
- **IndexedDB** – banco de dados NoSQL no navegador, para grandes volumes.  
- **Cache Storage** – armazena recursos (imagens, scripts) para uso offline (usado por PWAs).

⚠️ **Diferença importante:** **Cookies** são enviados automaticamente ao servidor a cada requisição; **Local/Session Storage** ficam apenas no cliente.

## 🛡️ Segurança e Privacidade

**Tópicos já mencionados:** certificados SSL/TLS, bloqueador de pop‑ups, filtro anti‑phishing, controle de privacidade, limpeza de dados, senhas salvas.

**Aprofundamento:**

- **Phishing** – tentativa de obter dados pessoais via sites ou e‑mails falsos.  
- **Pharming** – redirecionamento para site falso (por DNS ou host file).  
- **Spoofing** – falsificação de identidade (IP, e‑mail, DNS).  
- **Safe Browsing** – sistema do Google que alerta sobre sites maliciosos.  
- **Cadeado no navegador** – indica conexão HTTPS válida.  
- **Certificado inválido** – aviso de segurança ao acessar um site com certificado expirado ou não confiável.  
- **Downloads maliciosos** – o navegador pode bloquear downloads suspeitos.  
- **Extensões maliciosas** – podem acessar dados ou injetar anúncios.  
- **Ataques XSS (Cross‑Site Scripting)** – injeção de scripts maliciosos em páginas.  
- **CSRF (Cross‑Site Request Forgery)** – requisição não autorizada em nome do usuário autenticado.

## 🔍 Operadores de Busca

Os operadores de busca são caracteres e palavras‑chave especiais que refinam os resultados.

**Principais operadores (já existentes):**

| Operador | Função | Exemplo |
|----------|--------|---------|
| `" "` | Busca pela frase exata | `"curso de python"` |
| `-` | Exclui uma palavra | `receitas sem gluten -trigo` |
| `site:` | Restringe a um domínio | `iphone site:techtudo.com.br` |
| `filetype:` | Busca arquivos específicos | `manual camera nikon filetype:pdf` |
| `OR` | Busca um termo OU outro | `marketing digital OR SEO` |
| `related:` | Sites com conteúdo semelhante | `related:globo.com` |

**Acrescente:**

- `intitle:` – palavras no título da página.  
- `inurl:` – palavras na URL.  
- `before:` – resultados antes de uma data.  
- `after:` – resultados após uma data.  

⚠️ **O operador `~` (til) para sinônimos não é garantido no Google atualmente; evite decorá‑lo como regra.**

**Dica:** combine operadores: `site:gov.br "lei de cotas" filetype:pdf`

## 🔴 13. E‑mail e Webmail

**Importante:** este tópico frequentemente é cobrado junto com navegadores.

- **E‑mail** – sistema de troca de mensagens eletrônicas.  
- **Webmail** – acesso ao e‑mail via navegador (ex: Gmail, Outlook.com).  
- **Cliente de e‑mail** – programa instalado (ex: Outlook, Thunderbird).  

**Protocolos:**

- **SMTP** (Simple Mail Transfer Protocol) – envio de mensagens. Porta 25 ou 587.  
- **POP3** (Post Office Protocol) – recebimento/download (as mensagens geralmente são apagadas do servidor após download). Porta 110.  
- **IMAP** (Internet Message Access Protocol) – recebimento e sincronização (as mensagens permanecem no servidor). Porta 143.  

⚠️ **Pegadinha:** SMTP é para **envio**, não para receber mensagens.

- **CC** (Com Cópia) – cópia para outros destinatários (visível).  
- **CCO** (Com Cópia Oculta) – cópia oculta (os destinatários não veem quem está em CCO).  
- **Anexo** – arquivo enviado junto com a mensagem.  
- **Spam** – mensagens não solicitadas.  
- **Phishing** – tentativa de obter informações por e‑mail falso.  
- **MIME** (Multipurpose Internet Mail Extensions) – permite anexos e conteúdo multimídia.
