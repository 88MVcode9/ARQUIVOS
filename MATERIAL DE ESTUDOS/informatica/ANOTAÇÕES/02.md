
## 1. Conceitos fundamentais de Informática

- **Informática:** estudo do tratamento automatizado da informação por meio de computadores.
- **Computador:** máquina eletrônica capaz de processar dados e produzir informação.
- **Sistema computacional:** conjunto integrado de hardware, software e peopleware.
- **Dado:** elemento bruto, sem interpretação (ex.: número 35, letra ‘A’).  
  {IMAGEM: ilustração de dados crus (números e letras) sendo inseridos em um computador}
- **Informação:** dado processado e contextualizado, com significado (ex.: “temperatura atual = 35 °C”).  
  {IMAGEM: diagrama mostrando a transformação de dado em informação}
- **Processamento:** conjunto de operações que transformam dados em informação.  
  {IMAGEM: fluxo “Dados → Processamento → Informação”}

💡 **Pegadinha:** dado e informação **não são sinônimos**.

---

## 2. Sistema de Informação

Um sistema de informação segue um fluxo:

- **Entrada (Input):** dados inseridos no sistema.
- **Processamento:** tratamento dos dados.
- **Saída (Output):** informação produzida.
- **Armazenamento:** conservação dos dados/informações.
- **Feedback:** retorno utilizado para ajustes.

📌 **Fluxo:**  
**Entrada → Processamento → Saída → Armazenamento**

## 3. Elementos de um sistema informatizado

Todo sistema informatizado é formado por três elementos essenciais:

- **Hardware** – parte física, palpável.  
  Ex.: CPU, teclado, monitor, HD, placa‑mãe, mouse.  
  {IMAGEM: foto de componentes de hardware (placa‑mãe, processador, memória, etc.)}
- **Software** – parte lógica, programas e instruções. Não tem forma física.  
  Ex.: Windows, Word, Chrome, antivírus.  
  {IMAGEM: ícones de programas e sistemas operacionais}
- **Peopleware** – elemento humano: usuários, operadores, programadores.  
  {IMAGEM: pessoa utilizando um computador}

💡 **Bizu:** Hardware = físico (toca) | Software = programa (não toca) | Peopleware = usuário.

## 4. Hardware — CPU e componentes

A CPU é o cérebro do computador. **Não é o gabinete!**  
{IMAGEM: foto de um processador (chip) destacado}

### 4.1. Componentes internos da CPU

- **U.C. (Unidade de Controle):** coordena e sincroniza todas as operações.  
  {IMAGEM: representação da UC controlando fluxo de dados}
- **U.L.A. (Unidade Lógica e Aritmética):** executa operações aritméticas (soma, subtração) e lógicas (comparações).  
  {IMAGEM: esquema da ULA com entradas e saídas}
- **Registradores:** pequenas memórias internas de altíssima velocidade.  
  {IMAGEM: registradores como caixas dentro da CPU}
- **Cache:** memória de alta velocidade que armazena dados frequentemente usados.  
  {IMAGEM: hierarquia de memória com cache próxima à CPU}
- **Clock:** sinal que sincroniza as operações (medido em Hz).  
- **Núcleos (cores):** unidades de processamento independentes dentro da CPU.
- **Threads:** sequências de instruções executadas por um núcleo.

💡 **Pegadinha:** CPU ≠ gabinete. CPU é o processador.

## 8. Memórias

Ponto **muito importante** em concursos.

### 8.1. Hierarquia de memória

| Nível | Tipo | Velocidade | Volatilidade |
|-------|------|------------|--------------|
| 1     | Registradores | Altíssima | Volátil |
| 2     | Cache (L1, L2, L3) | Muito alta | Volátil |
| 3     | RAM | Alta | Volátil |
| 4     | SSD | Média | Não volátil |
| 5     | HD | Baixa | Não volátil |
| 6     | Fitas / nuvem | Muito baixa | Não volátil |

{IMAGEM: pirâmide da hierarquia de memória}

### 8.2. Memória principal

- **RAM** (Random Access Memory) – volátil (perde dados ao desligar).  
  {IMAGEM: pentes de memória RAM}
- **ROM** (Read‑Only Memory) – não volátil (mantém dados mesmo sem energia).  
  {IMAGEM: chip de ROM}
- **PROM** – programável uma única vez.
- **EPROM** – apagável por luz ultravioleta.
- **EEPROM** – apagável eletricamente (ex.: Flash).

### 8.3. Memória virtual

- Técnica que usa parte do HD/SSD como extensão da RAM.
- Mais lenta que a RAM física.

{IMAGEM: esquema de memória virtual}

💡 **Pegadinhas:**
- RAM = **volátil**.
- ROM = **não volátil**.
- Cache = muito rápida e próxima da CPU.
- HD/SSD = **armazenamento** (não são memória RAM).

## 9. Bits, Bytes e unidades de medida

- **Bit (b)** – menor unidade de informação, assume valor 0 ou 1.
- **Nibble** – conjunto de 4 bits.
- **Byte (B)** – conjunto de 8 bits.
- **KB, MB, GB, TB, PB, …**

| Unidade | Equivalência |
|---------|--------------|
| 1 Byte  | 8 bits       |
| 1 KB    | 1024 bytes   |
| 1 MB    | 1024 KB      |
| 1 GB    | 1024 MB      |
| 1 TB    | 1024 GB      |

⚠️ **Atenção** às diferenças:
- **b** = bit (velocidade de transmissão)
- **B** = Byte (armazenamento)

Exemplo:  
**100 Mbps ≠ 100 MB/s**

## 12. Sistema Operacional — Conceitos

### 12.1. O que é

Software responsável por gerenciar o hardware e fornecer serviços aos programas.
É a camada entre o hardware e os aplicativos.

**Exemplos:** Windows 10/11, Linux, Android, iOS, macOS.

{IMAGEM: camadas do sistema (Hardware → Kernel → SO → Aplicativos)}

### 12.2. Funções do SO

- Gerenciamento de **processos**
- Gerenciamento de **memória**
- Gerenciamento de **arquivos**
- Gerenciamento de **dispositivos** (via drivers)
- Gerenciamento de **usuários**
- Interface com o usuário (GUI ou CLI)

### 12.3. Kernel (núcleo)

É o núcleo central do SO. Gerencia diretamente o hardware: CPU, memória, dispositivos, processos e sistema de arquivos.

{IMAGEM: representação do kernel no centro do sistema}

### 12.4. Conceitos de execução

- **Programa:** código armazenado em disco (passivo).
- **Processo:** programa em execução (ativo).
- **Thread:** unidade menor de execução dentro de um processo.
- **PID (Process ID):** identificador único de cada processo.
- **Multitarefa:** execução aparentemente simultânea de vários processos.
- **Multiprocessamento:** uso de múltiplas CPUs/cores.
- **Multiusuário:** vários usuários simultâneos.
- **Interface GUI:** gráfica (Windows, macOS).
- **Interface CLI:** linha de comando (CMD, PowerShell, Terminal).

{IMAGEM: esquema mostrando programa, processo e threads}

💡 **Pegadinha:** um programa armazenado em disco **não** é um processo em execução.

### 12.5. Shell

- Interface entre o usuário e o kernel.
- Pode ser gráfico (GUI) ou linha de comando (CLI).

## 13. BIOS / UEFI / Boot

### 13.1. BIOS (Basic Input/Output System)

- Firmware tradicional.
- Inicializa e verifica componentes (POST).
- Suporte limitado a discos grandes (MBR).

### 13.2. UEFI (Unified Extensible Firmware Interface)

- Sucessora da BIOS.
- Interface gráfica.
- Suporte a discos >2 TB (GPT).
- Inicialização mais rápida.
- **Secure Boot:** impede a execução de software não autorizado durante a inicialização.

{IMAGEM: tela da BIOS vs. tela da UEFI}

### 13.3. Processo de inicialização (Boot)

1. **Ligação** – energia é fornecida.
2. **POST** – autoteste de verificação dos componentes básicos.
3. **BIOS/UEFI** – localiza e carrega o bootloader.
4. **Bootloader** – carrega o sistema operacional.
5. **SO** – inicializa o kernel e serviços.
6. **Sistema pronto** – usuário pode interagir.

{IMAGEM: fluxo do boot com cada etapa ilustrada}

💡 **Pegadinha:** BIOS/UEFI não é o sistema operacional.

## 14. Arquivos e sistemas de arquivos

### 14.1. Conceitos básicos

- **Arquivo:** unidade lógica de armazenamento.
- **Pasta/diretório:** contém arquivos e subpastas.
- **Caminho absoluto:** localização completa a partir da raiz (ex.: `C:\Users\joao\Documentos\relatorio.docx`).
- **Caminho relativo:** localização a partir do diretório atual (ex.: `Documentos\relatorio.docx`).
- **Extensão:** sufixo que identifica o tipo do arquivo.
- **Metadados:** informações sobre o arquivo (tamanho, data, atributos).

{IMAGEM: árvore de diretórios com pastas e arquivos}

### 14.2. Sistemas de arquivos

| Sistema | SO principal | Características |
|---------|--------------|-----------------|
| **NTFS** | Windows | Permissões, criptografia, arquivos grandes, journaling |
| **FAT32** | Compatível | Limite de 4 GB por arquivo |
| **exFAT** | Windows/macOS | Suporte a arquivos grandes, sem permissões |
| **EXT4** | Linux | Sistema padrão do Linux |

### 14.3. Outros conceitos

- **Partição:** divisão lógica de uma unidade de armazenamento.
- **Formatação:** preparação de uma unidade para receber um sistema de arquivos.
- **Arquivo oculto:** não é exibido por padrão no explorador.
- **Arquivo temporário:** usado pelo sistema ou aplicativos, pode ser excluído.

## 15. Compactação e Backup

### 15.1. Compactação

- **Com perda:** reduz tamanho com perda de qualidade (JPEG, MP3).
- **Sem perda:** mantém qualidade original (ZIP, PNG, FLAC).

| Formato | Característica |
|---------|----------------|
| ZIP     | Padrão no Windows |
| RAR     | Melhor compressão, pago |
| 7Z      | Alta compressão, open source |
| TAR/GZIP | Usado em Linux |
| ISO     | Imagem de disco |

{IMAGEM: ícones de arquivos compactados}

### 15.2. Backup

- **Completo:** cópia integral dos dados.
- **Incremental:** apenas alterações desde o último backup.
- **Diferencial:** alterações desde o último backup completo.

**Regra 3‑2‑1:**
- 3 cópias dos dados
- 2 mídias diferentes
- 1 cópia fora do local principal

### 17.3. Dispositivos de rede

### 17.4. Endereçamento

- **Porta:** identifica um serviço específico (ex.: 80 HTTP, 443 HTTPS).
- **DNS:** traduz nomes de domínio para IPs.

## 18. Internet e Web

### 18.1. Conceitos

- **Internet:** rede global de computadores.
- **Web (WWW):** serviço da Internet baseado em páginas HTTP.
- **Navegador:** programa para acessar a Web (Chrome, Firefox, Edge, Safari).
- **Site:** conjunto de páginas web.
- **URL:** endereço de um recurso (ex.: `https://www.exemplo.com/pagina`).
- **Domínio:** nome do site (ex.: `exemplo.com`).

### 18.2. Recursos do navegador

- **Cache:** armazena cópias de páginas para acesso mais rápido.
- **Cookies:** pequenos arquivos que armazenam preferências e sessões.
- **Histórico:** registro de páginas visitadas.
- **Favoritos/Marcadores:** páginas salvas.
- **Aba anônima/privada:** não salva histórico/cookies.
- **Extensões:** plugins que adicionam funcionalidades.

### 18.3. E‑mail

- **Webmail:** acessado via navegador (Gmail, Outlook).
- **Cliente de e‑mail:** programa instalado (Thunderbird, Outlook).

## 19. Segurança da Informação

⚠️ **Muito importante para concursos.**

### 19.1. Pilares da segurança

- **Confidencialidade:** acesso apenas por autorizados.
- **Integridade:** dados não são alterados indevidamente.
- **Disponibilidade:** dados acessíveis quando necessário.
- **Autenticidade:** garante a origem dos dados.
- **Não repúdio:** impede a negação de autoria.

{IMAGEM: triângulo CID (Confidencialidade, Integridade, Disponibilidade)}

### 19.2. Controles de acesso

- **Autenticação:** verifica identidade (senha, biometria, token).
- **MFA/2FA:** dois ou mais fatores de autenticação.
- **Controle de acesso:** quem pode fazer o quê.

### 19.3. Criptografia

- **Criptografia simétrica:** mesma chave para cifrar e decifrar.
- **Criptografia assimétrica:** par de chaves (pública e privada).
- **Certificado digital:** identidade digital (ex.: ICP‑Brasil).
- **Assinatura digital:** garante autenticidade e integridade.

### 19.4. Malwares

| Tipo | Característica |
|------|----------------|
| **Vírus** | Se replica e infecta arquivos |
| **Worm** | Se replica via rede, sem necessidade de arquivo hospedeiro |
| **Trojan** | Parece legítimo, mas tem função maliciosa |
| **Ransomware** | Criptografa dados e pede resgate |
| **Spyware** | Coleta informações do usuário |
| **Adware** | Exibe propagandas indesejadas |
| **Keylogger** | Registra teclas digitadas |
| **Rootkit** | Esconde a presença do malware no sistema |

### 19.5. Ataques e ameaças

| Tipo | Descrição |
|------|-----------|
| **Phishing** | Tentativa de obter dados via engano |
| **Pharming** | Redirecionamento para site falso |
| **Spoofing** | Falsificação de identidade (IP, e‑mail) |
| **Engenharia social** | Manipulação psicológica para obter informações |
| **Spam** | Mensagens não solicitadas em massa |

### 19.6. Proteção

- **Firewall:** bloqueia acessos não autorizados.
- **Antivírus:** detecta e remove malwares.
- **Backup:** recuperação em caso de ataque.
- **Atualizações:** corrigem vulnerabilidades.

## 17. Sistemas Operacionais — Conceitos (Complemento)

### Kernel (Núcleo)
- Núcleo central do SO.
- Gerencia diretamente o hardware.
- Controla processos, memória, sistema de arquivos e comunicação.

### Driver (Controlador)
- Programa que permite ao SO se comunicar com um dispositivo.
- Cada hardware precisa de um driver específico.
- Sem o driver correto → dispositivo não funciona.

### Codec
- Programa que codifica e decodifica arquivos de mídia.
- Necessário para reproduzir áudios e vídeos em determinados formatos.
- Exemplos: `H.264`, `MP3`, `AAC`, `HEVC (H.265)`.

💡 **Bizu:** Kernel = núcleo do SO | Driver = ponte entre SO e hardware | Codec = tradutor de arquivos de mídia.
