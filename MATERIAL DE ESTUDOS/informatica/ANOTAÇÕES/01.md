# INFORMÁTICA — Fundamentos e Conceitos Básicos

## 1. Conceitos fundamentais

- **Informática:** estudo do tratamento automatizado da informação por meio de computadores.
- **Computador:** máquina eletrônica capaz de processar dados e produzir informação.
- **Dado:** elemento bruto, sem interpretação (ex.: número 35, letra ‘A’).  
  {IMAGEM: ilustração de dados crus (números e letras) sendo inseridos em um computador}
- **Informação:** dado processado e contextualizado, com significado (ex.: “temperatura atual = 35 °C”).  
  {IMAGEM: diagrama mostrando a transformação de dado em informação}
- **Processamento:** conjunto de operações que transformam dados em informação.  
  {IMAGEM: fluxo “Dados → Processamento → Informação”}

💡 **Pegadinha:** dado e informação **não são sinônimos**.

---

## 2. Elementos de um sistema informatizado

Todo sistema informatizado é formado por três elementos essenciais:

- **Hardware** – parte física, palpável.  
  Ex.: CPU, teclado, monitor, HD, placa‑mãe, mouse.  
  {IMAGEM: foto de componentes de hardware (placa‑mãe, processador, memória, etc.)}
- **Software** – parte lógica, programas e instruções. Não tem forma física.  
  Ex.: Windows, Word, Chrome, antivírus.  
  {IMAGEM: ícones de programas e sistemas operacionais}
- **Peopleware** – elemento humano: usuários, operadores, programadores.  
  {IMAGEM: pessoa utilizando um computador}

💡 **Bizu:** Hardware = físico (toca) | Software = programa (não toca) | Peopleware = usuário.

## 3. Sistema de Informação

Um sistema de informação não se resume a hardware/software; ele segue um fluxo:

- **Entrada (Input):** dados inseridos no sistema.  
  {IMAGEM: teclado, mouse, scanner sendo usados para inserir dados}
- **Processamento:** tratamento dos dados (cálculos, ordenação, etc.).  
  {IMAGEM: engrenagens ou circuito processando dados}
- **Saída (Output):** informação produzida e apresentada.  
  {IMAGEM: monitor mostrando relatório ou gráfico}
- **Armazenamento:** conservação dos dados/informações para uso futuro.  
  {IMAGEM: discos rígidos, pendrives, nuvem}
- **Feedback:** retorno utilizado para ajustes e melhorias.  
  {IMAGEM: seta de retorno no fluxo}

📌 **Fluxo:**  
**Entrada → Processamento → Saída → Armazenamento**

## 4. Hardware — CPU (Unidade Central de Processamento)

A CPU é o cérebro do computador. **Não é o gabinete!**  
{IMAGEM: foto de um processador (chip) destacado}

Principais componentes internos:

- **U.C. (Unidade de Controle):** coordena e sincroniza todas as operações.  
  {IMAGEM: representação da UC controlando fluxo de dados}
- **U.L.A. (Unidade Lógica e Aritmética):** executa operações aritméticas (soma, subtração) e lógicas (comparações).  
  {IMAGEM: esquema da ULA com entradas e saídas}
- **Registradores:** pequenas memórias internas de altíssima velocidade.  
  {IMAGEM: registradores como caixas dentro da CPU}
- **Cache:** memória de alta velocidade que armazena dados frequentemente usados para reduzir tempo de acesso.  
  {IMAGEM: hierarquia de memória com cache próxima à CPU}

💡 **Pegadinha:** CPU ≠ gabinete. CPU é o processador.

## 5. Memórias

Ponto **muito importante** em concursos.

### 5.1. Memória principal

- **RAM** (Random Access Memory) – volátil (perde dados ao desligar).  
  {IMAGEM: pentes de memória RAM}
- **ROM** (Read‑Only Memory) – não volátil (mantém dados mesmo sem energia).  
  {IMAGEM: chip de ROM}

### 5.2. Memória cache

- Memória de alta velocidade, integrada ou próxima à CPU.  
  {IMAGEM: níveis de cache L1, L2, L3}

### 5.3. Memórias secundárias / armazenamento

- HD (disco rígido)  
- SSD (unidade de estado sólido)  
- Pen drive  
- Cartão de memória  
- CD/DVD/Blu‑ray  
  {IMAGEM: exemplos de cada dispositivo de armazenamento}

💡 **Pegadinhas:**
- RAM = **volátil**.
- ROM = **não volátil**.
- SSD/HD = **armazenamento** (não são memória RAM).

### 7.1. Classificações por função

- **Software de sistema:**  
  - Sistemas operacionais (Windows, Linux, macOS, Android, iOS)  
  - Drivers  
  - Firmware  
  {IMAGEM: tela do Windows, do Linux, do macOS}

- **Software aplicativo:**  
  - Word, Excel, Chrome, Photoshop  
  {IMAGEM: ícones do pacote Office, navegadores, etc.}

- **Software utilitário:**  
  - Antivírus, compactadores (WinZip, 7‑Zip), ferramentas de backup  
  {IMAGEM: ícones de antivírus e de compactadores}

### 7.2. Classificações por licenciamento / distribuição

- **Proprietário:** código fechado, comercial (ex.: Windows, Adobe Photoshop).
- **Livre:** código aberto, pode ser modificado e redistribuído (ex.: Linux, GIMP).  
- **Open source:** código aberto (similar ao livre, mas com critérios específicos).
- **Freeware:** gratuito, mas código fechado (ex.: Adobe Reader, CCleaner).
- **Shareware:** uso gratuito por tempo limitado ou com funcionalidades restritas.
- **Trial:** versão de teste por tempo determinado.

## 8. Firmware

**Firmware** é um software gravado em um chip de hardware, responsável por controlar funções básicas do equipamento.

- Não é volátil (mantém-se mesmo desligado).
- Exemplos: BIOS/UEFI, firmware de roteadores, firmware de impressoras.  
  {IMAGEM: chip de firmware em uma placa‑mãe}

💡 **Pegadinha:** firmware é **software**, mesmo estando diretamente associado ao hardware.

## 10. Inicialização do computador (Boot)

Processo de inicialização:

1. **Ligação** – energia é fornecida.
2. **POST** (Power‑On Self‑Test) – verificação dos componentes básicos.
3. **BIOS/UEFI** – firmware que localiza e carrega o sistema operacional.
4. **Carregamento do SO** – kernel e serviços são iniciados.
5. **Sistema pronto** – usuário pode interagir.

{IMAGEM: fluxo do boot com cada etapa ilustrada}

💡 **Pegadinha:** BIOS/UEFI não é o sistema operacional.

---

## 11. BIOS × UEFI

- **BIOS** (Basic Input/Output System):  
  - Firmware tradicional.  
  - Interface em modo texto.  
  - Suporte limitado a discos grandes (MBR).  

- **UEFI** (Unified Extensible Firmware Interface):  
  - Sucessora da BIOS, mais moderna.  
  - Interface gráfica.  
  - Suporta discos maiores que 2 TB (GPT).  
  - Inicialização mais rápida e flexível.

## 13. Bits e Bytes

- **Bit** (b) – menor unidade de informação, assume valor 0 ou 1.  
- **Byte** (B) – conjunto de 8 bits.  

Múltiplos:
- KB, MB, GB, TB, PB, …

⚠️ **Atenção** às diferenças entre:
- **b** = bit  
- **B** = Byte  

Exemplo:  
**100 Mbps ≠ 100 MB/s** (megabits por segundo ≠ megabytes por segundo).

## 14. Arquivos e pastas

Conceitos básicos:

- **Arquivo** – unidade lógica de armazenamento de dados.  
- **Pasta / Diretório** – local que contém arquivos e subpastas.  
- **Subpasta** – pasta dentro de outra.  
- **Extensão** – sufixo após o ponto que identifica o tipo do arquivo.  
- **Caminho** – localização hierárquica (ex.: `C:\Users\Documentos\relatorio.docx`).  
- **Unidade de armazenamento** – letra (C:, D:, etc.) ou montagem no Linux.  
- **Nome do arquivo** – identificador; pode conter letras, números e alguns caracteres.

## 15. Processos e multitarefa

- **Programa:** código armazenado em disco (passivo).  
- **Processo:** programa em execução (ativo).  
- **Thread:** unidade menor de execução dentro de um processo.  
- **Multitarefa:** capacidade do sistema operacional de executar vários processos aparentemente ao mesmo tempo.  
- **Multiprocessamento:** uso de múltiplas CPUs/cores para executar processos paralelamente.

{IMAGEM: esquema mostrando programa, processo e threads}

💡 **Pegadinha:** um programa armazenado no disco **não** é a mesma coisa que um processo em execução.
